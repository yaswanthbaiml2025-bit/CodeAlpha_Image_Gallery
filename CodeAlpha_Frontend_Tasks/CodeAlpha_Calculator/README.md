# CodeAlpha Task 2 — Calculator

## Features
- Addition, subtraction, multiplication and division
- Decimal input, clear and delete
- Keyboard input (digits, decimal, operators, Enter, Backspace, Escape)
- Handles division by zero
- Responsive dark interface

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Test checklist
1. `8 + 4 =` should show `12`.
2. `9 - 5 =` should show `4`.
3. `6 × 7 =` should show `42`.
4. `8 ÷ 2 =` should show `4`.
5. `5 ÷ 0 =` should show `Cannot divide by zero`.
6. Test decimals, AC, DEL and keyboard controls.
