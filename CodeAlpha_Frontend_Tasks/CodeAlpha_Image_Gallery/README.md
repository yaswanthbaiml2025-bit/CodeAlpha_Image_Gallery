# CodeAlpha Task 1 — Image Gallery

## Features
- Responsive image grid
- Category filters (All, Nature, Travel, Architecture)
- Lightbox with next/previous controls
- Keyboard navigation (left/right arrows and Escape)
- Hover transitions and accessible labels

## Run
Open `index.html` in a browser, or use VS Code Live Server.
Internet is needed to load the demo photos from Unsplash.

## Test checklist
1. Open the page at desktop and mobile widths.
2. Click each category filter and confirm only matching cards remain.
3. Open a photo; test next, previous, close button, background click and Escape.
4. With the lightbox open, test left/right arrow keys.
